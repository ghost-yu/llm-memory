## 3. 基础概念与张量路线【必须会】

Associative memory 的任务是从 key 找回 value。一个最简单的线性版本是：

$$k_t\in\mathbb R^{d_k},\quad v_t\in\mathbb R^{d_v},\quad W_t\in\mathbb R^{d_v\times d_k},\quad \hat v_t=W_{t-1}k_t.$$

$t$ 是序列位置；$k_t$ 是写入地址；$v_t$ 是想在该地址存下的内容；$W_t$ 是写入后的状态。读取时用 query $q_t$，计算 $W_tq_t$。本实验故意使用 one-hot key，便于把一个地址的更新算清楚。论文的语言模型则通过可训练投影从 token 表示生成 key、value、query。

状态是浮点矩阵或 MLP 参数，不是一张字符串字典。输入新 token 时计算误差、梯度并改状态；测试时可以进行这种内循环更新。离线训练负责学习初始参数、投影及更新超参数。测试时更新快状态与重新训练整个语言模型是不同范围的操作。

MIRAS 的四个选择：

| 设计轴 | 直观问题 | 常见选择 | 本实验选择 |
|---|---|---|---|
| Memory architecture | 用什么函数存 key→value？ | 矩阵、两层 MLP、非参数结构 | 线性矩阵 |
| Attentional bias | 什么错误应推动记忆变化？ | 点积目标、平方误差、p 范数、Huber | 平方误差与 Huber |
| Retention | 新信息进来时如何保留旧状态？ | 欧氏距离、衰减、KL、其他散度 | 比较实验 α=1；另测衰减/KL |
| Learning algorithm | 怎样求解更新？ | 梯度下降、镜像下降及近似 | 显式单步梯度更新 |

这里的 attentional bias 是优化目标对信息的偏好，不是另加一个 Softmax attention 模块，也不是“人类真的这样存记忆”的实验结论。

## 4. 为什么遗忘门可以看作正则化【必须会】

Learning-Retaining 视角（§3.3）写成：

$$W_t=\arg\min_{W\in\mathcal W}\ \widetilde\ell_t(W;k_t,v_t)+\operatorname{Ret}_t(W,W_{t-1}).$$

$\mathcal W$ 是允许的状态空间；$\widetilde\ell_t$ 是新样本损失或其局部近似；$\operatorname{Ret}$ 约束变化。新信息要求状态改变，旧知识要求状态别变太多。

取 $g_t=\nabla_W\ell(W_{t-1};k_t,v_t)$，局部线性近似为 $\langle W-W_{t-1},g_t\rangle$，再取欧氏局部保留与二次全局正则。为了便于推导，这里用明确的二分之一系数写一个特例：

$$\operatorname{Ret}(W,W_{t-1})=\frac1{2\eta}\|W-W_{t-1}\|_F^2+\frac\lambda2\|W\|_F^2.$$

设导数为零，得到：

$$W_t=\frac{1}{1+\eta\lambda}W_{t-1}-\frac{\eta}{1+\eta\lambda}g_t.$$

因此“把旧状态乘小于 1 的系数”可以来自全局正则。这是等价来源，不代表所有工程门都必须由同一系数绑定。论文在 §5.3 又把学习率与保留率解耦为可独立学习的参数。

数值例：$W_{t-1}=1,\eta=0.2,\lambda=1,g_t=0$，则 $W_t=1/1.2=0.8333$。即便当前没有新误差，全局约束仍使旧记忆减弱。代码独立检验 $\alpha=0.98$ 且梯度为零时状态变成原来的 98%。主比较用 $\alpha=1$，以免把目标函数差异与遗忘混在一起。

FTRL（Follow-the-Regularized-Leader）视角则累计过去的近似损失并加正则，再求一个状态。§3.4 Proposition 3.2 在固定步长、全空间以及严格凸等条件下，用累计目标构造 Bregman divergence，将它连接到 Learning-Retaining。不能把这个带条件的联系推广成“任意非凸 MLP 两种算法都无条件等价”。证明推导属于【建议会】。

## 5. 平方误差为何会被异常写入破坏【必须会】

为固定梯度尺度，这里用半平方误差：

$$\ell_2(W;k,v)=\frac12\|Wk-v\|_2^2,\qquad g=(Wk-v)k^\top.$$

预测残差 $e=Wk-v\in\mathbb R^{d_v}$；$e k^\top\in\mathbb R^{d_v\times d_k}$，与状态形状一致。更新为 $W'=\alpha W-\eta g$。

代码的 $W$ 形状是 [1,8]，$k$ 是 [8]，$v$ 是标量。$W@k$ 得到 [1]，squeeze 去掉大小为 1 的维度得到标量。$k.unsqueeze(0)$ 得到 [1,8]，乘标量残差便得到梯度。Python 的 @ 在这里表示矩阵乘法；广播是标量作用到矩阵每个元素。

已有值为 1，新观测错误地声称 21，$\eta=0.2,\alpha=1$。此时 $e=1-21=-20$，平方误差的更新为 $1-0.2(-20)=5$。一个错误记录把正确记忆从 1 推到了 5。对 one-hot key，其他地址不会直接受这一梯度影响；论文里的共享 MLP 和非正交地址会更复杂，本实验不声称验证了共享参数干扰。

## 6. Huber 与 Yaad：控制异常写入【必须会】

公式 13 的标量 Huber 函数是：

$$\mathcal H_\delta(e)=\begin{cases}\frac12e^2,&|e|\le\delta,\\\delta(|e|-\frac12\delta),&|e|>\delta.\end{cases}$$

其导数为 $\operatorname{clip}(e,-\delta,\delta)$。近处仍细调，远处只允许有限写入。在线性标量输出情况下，Yaad 的公式 26 简化为：

$$W_t=\alpha_tW_{t-1}-\eta_t\operatorname{clip}(W_{t-1}k_t-v_t,-\delta,\delta)k_t^\top.$$

沿用上例并设 $\delta=0.5$：梯度残差被限制为 −0.5，状态变成 $1-0.2(-0.5)=1.1$，而不是 5。它没有判断观测真假，只是限制大误差造成的单步改动。若 21 真的是新值，限制也会拖慢学习。

需要辨清论文给出的三个 Huber-type 方案：公式 13—14 对每个坐标应用 Huber；公式 15 对整个残差的 L2 范数做 Huber，远处梯度是归一化残差；公式 16 及 Yaad 公式 26 用整体范数选分支，在大误差分支用 $\delta\nabla\ell_1$。多输出时，这三个版本不完全相同。本实验只有一个输出，绝对值与 L2 范数一致、归一化残差与 sign 一致，因此能同时解释这一标量特例。不能把 scalar clamp 直接声称为完整多维 Yaad 实现。

Yaad 的完整模型使用两层 MLP、输入相关的 $\delta_t$、学习率、通道保留参数及语言模型外围结构。本实验固定 $\delta=0.5$ 和 $\eta=0.2$，没有外循环训练这些参数。

## 7. Moneta：目标与保留几何都能改变【建议会】

Moneta 使用两层、扩展因子 4 的 GELU MLP，以及残差和 LayerNorm，原文写为：

$$\mathcal M(x)=x+\operatorname{LN}(W_1\sigma(W_2x)).$$

若输入 $x\in\mathbb R^d$，可按列向量约定令 $W_2\in\mathbb R^{4d\times d},W_1\in\mathbb R^{d\times4d}$。GELU 是平滑非线性，LN 是 LayerNorm。残差保证输入有一条直接到输出的路径。$\sigma$ 在此表示 GELU，不要与后面其他段落的 sigmoid 符号混淆。

线性记忆的 p 次残差目标为：

$$\ell_p=\sum_j|e_j|^p,\qquad\nabla_W\ell_p=p\bigl(\operatorname{sign}(e)\odot|e|^{p-1}\bigr)k^\top.$$

$p$ 决定误差权重；$\odot$ 是逐元素乘。$p=3$ 时残差 2 的梯度权重为 $3\times2^2=12$，并不等于 Huber 的大误差截断，所以不要将“Moneta 在某任务表现抗噪”解读成其梯度处处有界。

公式 24 引入双变量 $A$：

$$A_t=\alpha_tA_{t-1}-\eta_t\nabla\ell_p(W_{t-1};k_t,v_t),\qquad W_t=\frac{A_t}{\|A_t\|_q^{q-2}}.$$

论文使用 $(p,q)=(3,4)$。$p$ 是写入目标参数，$q$ 是保留几何参数。两者不能混成一个参数。$q=2$ 时分母为 1；$q=4$ 时范数平方参与状态映射。标量例：$A=2,q=4$，得到 $W=2/2^2=0.5$；$A=0$ 时式子需要额外数值处理。完整 MLP 实现还必须明确范数按哪个参数张量或切片计算。本地未找到官方实现来确认这些细节，故未把随意选择的归一化加入实验。

原文公式 25 的梯度表达式额外出现 $\eta_t$，而公式 11 与 24 已分别表示梯度和学习率；本文按求导结果把梯度与步长分开，不把步长乘两次。公式中的线性 $Wk$ 只是用于说明；对 MLP 参数求导须经过链式法则，不能直接用该外积替代。

## 8. Memora：用 KL 保留与 simplex 状态【建议会】

公式 27 为：

$$W_t=\operatorname{Softmax}\bigl(\alpha_t\log W_{t-1}-\eta_t\nabla\ell_2(W_{t-1};k_t,v_t)\bigr).$$

状态需为正，才能取 log。Softmax 保证输出正值且在指定归一化范围内和为 1。$\alpha$ 作用于旧状态的 log，不能理解成简单的 $\alpha W$。无新梯度时，$W'\propto W^\alpha$；当 $\alpha<1$，概率分布倾向变平，原有强偏好减弱。

本地 checks() 只验证这一更新算子的性质：对 [4,4] 状态沿 dim=0 做每列 Softmax，连续 100 次更新仍保持正值且每列和为 1。选择每列 normalization 是教学实验明确规定的切片，不声称它是官方完整 MLP 实现的归一化约定。另一例从 [0.7,0.1,0.1,0.1] 出发，无梯度且 α=0.5，熵由 0.94045 升至 1.27495，显示旧偏好变弱。

原文 Memora 段落开头提到 elastic net，但紧接着的设计清单指定 KL，公式 27 也确实是 log/Softmax 更新。本文以清单和方程为依据区分它与公式 22 的 soft-threshold elastic-net 更新。不能将 Softmax 说成 soft-threshold，后者还会把足够小的系数直接置零。


### 8.1 从优化问题到 log/Softmax：归一化范围与符号【建议会】

公式 19—21 的任务是同时保留旧分布和限制新状态的偏好强度。将矩阵各元素视为一个联合分布，原文公式 20 是 $\sum_{i,j}W_{ij}=s,\ W_{ij}\ge0$，不是自动规定每列和为 1。$i=1,\ldots,d_v$ 是行，$j=1,\ldots,d_k$ 是列；$s>0$ 是总质量；$W,W_{t-1},g\in\mathbb R^{d_v\times d_k}$ 是浮点矩阵，$g=\nabla\ell(W_{t-1};k_t,v_t)$。写出公式 19：

$$\min_W\ \langle W-W_{t-1},g\rangle+\frac1{\eta_t}\sum_{i,j}W_{ij}\log\frac{W_{ij}}{(W_{t-1})_{ij}}+\frac1{\alpha_t}\sum_{i,j}W_{ij}\log W_{ij},\quad\sum_{i,j}W_{ij}=s.$$

此处 $\eta_t,\alpha_t>0$ 是两个正则项的尺度；这里的 $\alpha_t$ 出现在分母，**不等于** demo 中直接乘旧状态的保留率 alpha。内积是逐元素乘后求和，返回标量。步骤是：添加总质量约束的拉格朗日乘子；逐元素求导；把 $\log W_{ij}$ 移到一边；指数化；用归一化常数消去乘子。令

$$\beta_t=\frac{1/\alpha_t}{1/\alpha_t+1/\eta_t},\qquad\eta'_t=\frac1{1/\alpha_t+1/\eta_t},$$

得到公式 21：

$$W_t=s\operatorname{Softmax}_{i,j}\!\left((1-\beta_t)\log W_{t-1}-\eta'_t g\right).$$

所有操作保持矩阵布局，Softmax 在这里跨全部 $d_vd_k$ 个元素归一化。例如 $\eta_t=\alpha_t=1$，则 $\beta_t=0.5,\eta'_t=0.5$；旧状态 [0.7,0.1,0.1,0.1]、梯度 0、$s=1$，新状态正比于其平方根，约 [0.4686,0.1771,0.1771,0.1771]。它让旧偏好变平。公式 27 又把 log 前的保留率与梯度前的步长作为独立可学习量，因此不能把两处同名字母直接代成同一配置。

本地 checks() 使用 torch.softmax(...,dim=0)。维度 0 指矩阵行方向，故每一列独立归一化。新脚本 [trace_contracts.py](复现/scripts/trace_contracts.py) 用 logits=[[1,2],[3,4]] 实测：联合 Softmax 总和=1；每列 Softmax 列和各为 1，总和约 2，二者确实不同。原文第 11 页允许按参数切片归一化，但缺官方代码时不能确定实际 MLP 的切片。这里“本地选择”不是论文“只能如此”。对应原页：[公式 19—21](图片/page-11.png)。

### 8.2 Elastic net、Bregman 与 FTRL 的具体区别【建议会】

Soft-threshold 的用途是将小系数直接归零，而不只是变平。原文第 12 页公式 22 的符号为：

$$W_t=S_\gamma(\lambda W_{t-1}-\zeta g),\quad S_\gamma(z)=\operatorname{sign}(z)\max(0,|z|-\gamma),$$

$$\gamma=\frac{\eta\beta}{\alpha(\eta+\beta)},\quad\lambda=\frac\beta{\beta+\eta},\quad\zeta=\eta\lambda.$$

$\eta,\alpha,\beta>0$ 为正则/步长尺度，$\lambda\in(0,1)$ 是保留系数，$\zeta$ 是有效步长，$\gamma$ 是归零阈值；这里 $\lambda$ 与 §4 为教学推导另设的二次正则系数不同。$z,W,g$ 同为状态形状；$S_\gamma$ 逐元素作用。先乘旧状态，再减梯度，最后做阈值收缩。例取三个尺度均为 1，则 $\lambda=\zeta=\gamma=0.5$；$W_{t-1}=[0.4,2],g=0$，先得到 [0.2,1]，再变成 [0,0.5]。第一个系数完全归零，第二个继续减小。该式及数值是数学分析，本地 write() **未实现** $S_\gamma$。

公式 23 则保存累计双变量：$A_t=A_{t-1}-\eta g_t,\ W_t=S_{\eta/\alpha}(A_t)$，从 $A_0=0$ 起步。$A,W,g$ 形状一致；$t$ 是当前步。它先累加梯度，再从累计量恢复状态，与每次直接对旧 $W$ 阈值处理的公式 22 不同。标量例 $\eta=\alpha=1,g_1=-0.4,g_2=-0.8$：$A_1=0.4,W_1=0$；$A_2=1.2,W_2=0.2$，第一步尚未显示的累计量并没有丢失。本地没有实现此累计状态。原文阈值平滑近似与边界导数属于【可以暂时不掌握】，不能以此替代未运行的官方内核。[公式 22—23 原页](图片/page-12.png)。

Bregman divergence 的正确标准定义（第 6 页 Proposition 3.2）是

$$D_h(W,W')=h(W)-h(W')-\langle\nabla h(W'),W-W'\rangle.$$

$h$ 是可微严格凸的标量函数；$W,W'$ 可展开为长度 $n$ 的浮点向量，梯度也长 $n$，内积返回标量。它扣去在旧点的切平面，量度新点比局部线性预测高多少。例 $h(w)=w^2/2,w=2,w'=1$，得到 $2-0.5-1(2-1)=0.5$。矩阵情形相应是半平方 Frobenius 距离。第 12 页底部显示的定义用 $\langle W',W-W'\rangle$，对一般 $F$ 不能代替 $\nabla F(W')$；这里按第 6 页的明确定义解释，保留这一原文记号疑点。

FTRL 用全部过去的近似损失求状态；Learning-Retaining 用当前近似损失和旧状态距离求状态。固定 $\eta$、$W_0=0$、线性近似梯度 $g_i$ 及正则 $\|W\|_F^2/(2\eta)$ 时，累计目标的一阶条件给出 $W_t=-\eta\sum_{i=1}^t g_i$；逐步更新 $W_t=W_{t-1}-\eta g_t$ 给出同一个值。例 $\eta=0.1,g_1=2,g_2=-1$，两条路径均得到 −0.1。一般 Proposition 3.2 使用 $h_t=\sum_{i=1}^{t-1}\widetilde\ell_i+R/\eta$ 构造距离，要求严格凸、全空间且固定步长等条件；不能将任意损失的欧氏距离直接称为该累计 $h_t$。这里无官方对应函数，本地解析 write 只演示其梯度下降特例。f-divergence 通用逆函数构造及证明全文列为【可以暂时不掌握】，不声称完成所有变体实现。

## 9. 图 2：完整模型的数据流【建议会】

[图 2 原页](图片/page-14.png)的右侧是 MIRAS layer：token 表示先分支投影，q/k/v 分支经过卷积，q/k 还做归一化，其他分支生成学习率与保留参数。记忆层接收这些量并进行读取和更新，输出经过 normalization 和门控。左侧将 MIRAS layer 放在带 RMSNorm、残差、SwiGLU 的语言模型 block 中。中间是加了 Sliding Window Attention（SWA）的 hybrid 版本。

以常用批处理形状描述：输入 [B,T,d] → 投影 q/k/v [B,T,d_head] → 每个批样本和记忆 head 的状态 → 写入后读取 [B,T,d_head] → 合并、门控和输出投影 → [B,T,d]。B 是 batch 数，T 是 token 数。精确的 head 参数布局与权重共享仍需官方配置确认，此处是形状约定说明，不是从代码读出的事实。

Linear、卷积、MLP、归一化与门参数通常参与离线训练；测试时的快记忆状态按在线规则更新。Q/K 的范数归一化是运算，归一化层是否带仿射参数需看具体实现。本地 demo 没有这些语言模型模块，它的实际路线更短：随机生成地址与值 → one-hot key → 矩阵读取 → 残差 → write() → 更新矩阵 → 对八个地址重新读取评估。


### 9.1 按箭头读图，而不是猜模块【建议会】

图 2 三栏都从下往上读。左栏 Input → RMSNorm → MIRAS layer → 加号处合并第一条虚线残差 → RMSNorm → SwiGLU → 加号处合并第二条虚线残差 → Output。虚线是绕过子模块的路径；加号表示逐元素相加，要求两条支路形状相同。中栏顺序为 MIRAS layer → MLP → 残差相加 → SWA → MLP → 残差相加；不能把它描述成同时平行算出两种记忆再求和。

右栏输入分叉：q/k/v 的 Linear 投影之后有 Conv；q/k 的 Norm 进入记忆匹配，v 用作拟合目标；中央低秩投影生成学习率/保留量；最右 Linear 形成门控支路。记忆输出向上经过 Norm，在顶端乘号与门支路逐元素相乘。图中小圆圈没有逐一标出激活名，不能仅看图自行指定 sigmoid/SiLU。正文明确卷积 kernel=4、q/k 的 L2 normalization 和 channel-wise 参数，阈值 $\delta_t$ 的实际布线及投影激活还需实现确认。

Linear 是带可训练权重的映射，depthwise convolution 是有参数的局部时序滤波，RMSNorm/SwiGLU/记忆 MLP 通常也有离线可训练参数；残差加法、逐元素乘法、q/k 范数运算本身不新增参数。低秩通道参数的说明为 $x_t[d]\to h_t[r]\to\eta_t,\alpha_t,\delta_t[d]$，常用 $r=32$ 或 64，减少直接 d→d 投影的参数量；是否三组共享投影未由本地代码确认。对于一条长度 T 的样本，先生成每个位置的 q/k/v，再按在线/冻结 chunk 规则变更快状态，然后读出结果送回 residual stream。与经典 attention 的 KV cache 不同，这里核心是固定布局状态的更新；hybrid SWA 另有窗口 attention，精确推理缓存布局未找到。

完整 LM 还须有 tokenizer、词表、Embedding、LM head 和 next-token loss。正文给出了 Llama 宏结构、RoPE、RMSNorm、SwiGLU；本文不据此补造确切 tokenizer/词表大小、head 布局或参数共享配置。demo 中这些模块、SFT/偏好优化、解码、量化、GPU 并行均未实现，输出是浮点检索值，不是生成 token。训练与推理都可以写入快状态，但本地不验证外循环反传。图中各框与官方类名的映射均“未找到”；线性记忆框的单输出机制对应本地 write()。这是明确的代码边界，不是用假模型补图。

## 10. chunk 并行训练有近似边界【建议会】

§5.4 通常把序列分成 16 或 64 长的 chunk。在一个 chunk 内，所有 token 的梯度使用同一份旧状态算，而不是每一步都用刚更新后的状态。这样可批量求梯度，再使用线性递推或矩阵运算聚合。它改变了梯度求值位置，不能笼统地说“与逐 token 更新完全相同”。

令当前 chunk 起点为 s，冻结参考状态为 $W_s$，$g_i=\nabla\ell(W_s;k_i,v_i)$，则线性递推的展开为：

$$W_t=\Bigl(\prod_{j=s+1}^{t}\alpha_j\Bigr)W_s-\sum_{i=s+1}^{t}\eta_i\Bigl(\prod_{j=i+1}^{t}\alpha_j\Bigr)g_i.$$

乘积说明早写入的信息会经过后续保留门。例：$W_s=1,\alpha=0.9,\eta=0.1,g_1=2,g_2=3$，则 $W_1=0.7,W_2=0.33$；展开式为 $0.81-0.1(0.9\times2+3)=0.33$。

对 Moneta 的非线性状态映射，论文在 chunk 末处理；Memora 的 log/Softmax 更麻烦，原文讨论 lag token 方案（公式 30—32），不能直接套成普通线性 scan。原文公式 28 旁的 chunk 索引文字与“前一 chunk 最后状态”的解释存在排版疑点，本文用 s 明确表达冻结参考点，未照抄可疑索引为可执行代码。

本实验是顺序在线写入，完全不测试 chunk 加速、GPU 吞吐或外循环反向传播。它的速度不能拿来评估论文的系统性能。


### 10.1 公式 29—32 的矩阵形状与 lag token【建议会】

并行化的目的不是改名成“batch”，而是把同一 chunk 内的梯度用矩阵乘法一起计算。以下明确采用列样本约定：$b$ 为 chunk 长度，$K=[k_1,\ldots,k_b]\in\mathbb R^{d_k\times b}$，$V=[v_1,\ldots,v_b]\in\mathbb R^{d_v\times b}$，冻结矩阵 $W_*\in\mathbb R^{d_v\times d_k}$，$R=W_*K-V\in\mathbb R^{d_v\times b}$。$\beta_i=\prod_{j=1}^i\alpha_j$ 是累计保留率，$E=[\eta_1,\ldots,\eta_b]$、$B=[\beta_b/\beta_1,\ldots,\beta_b/\beta_b]$ 均是 [1,b] 行；权重 $C=E\odot B$ 广播到每个 value 坐标。

在这一布局下，公式 29 的加权 p 梯度和应按形状重写为：

$$\sum_{i=1}^b\eta_i\frac{\beta_b}{\beta_i}g_i=\left[p\operatorname{sign}(R)\odot|R|^{p-1}\odot C\right]K^\top.$$

先生成残差 [d_v,b]；逐元素 sign/绝对值幂及p仍为 [d_v,b]；乘 C 加上每条样本的步长/后续遗忘；最后乘 $K^\top[b,d_k]$ 得 [d_v,d_k] 梯度和。p是误差目标指数，不是chunk长度；本文用括号显式规定逐元素乘发生在矩阵乘法之前，原式29右侧同时出现未合并的单token残差符号，不能按其排版直接抄成广播代码。原文训练采用 sign(x)≈tanh(a x)、|x|≈sqrt(x²+epsilon)，epsilon=1e-6；a是平滑强度，不要与记忆保留率alpha混淆。q≠2 的状态非线性归一化在chunk边界应用，因此不能说这是每token原式24的精确逐步执行。

Memora 的公式30先对边界之后的 lag token 更新一次：

$$M_1=\operatorname{Softmax}(\alpha_1\log M_0-\eta_1\nabla\ell_2(M_0;k_1,v_1)).$$

下标0/1是此处重新记的旧状态与lag更新后状态，不是把所有序列都重置为零。M0必须为正；Softmax归一化范围仍要明确。无梯度、alpha1=.5、旧状态 [.8,.2] 时，lag步骤得到 [2/3,1/3]，因为平方根比例为2:1。随后将 M1（线性说明时为 W1）作为下一段冻结参考，公式31为 $g_i=(W_1k_i-v_i)k_i^\top$；公式32的维度一致形式为：

$$\sum_{i=1}^b\eta_i\frac{\beta_b}{\beta_i}g_i=\left[(W_1K-V)\odot C\right]K^\top.$$

例：仅为展示加权求和，取标量 W1=.5、两个key均1、目标[0,1]、步长均.1、保留率均.9。冻结残差为 [.5,-.5]，权重为 [.09,.1]，梯度和=.045-.05=−.005。该线性递推的chunk末状态为 .81×.5−(−.005)=.410。实际Memora边界还涉及log/Softmax，不把.410说成完整Memora输出。这里只解释原文矩阵化与近似的来源；本地 write/checks/stream 未实现这些chunk或lag路径，官方类/内核“未找到”。[公式28—32原页](图片/page-15.png)。

eta/alpha/delta 在此代码中按数值配置使用；函数未强制检查 positivity、上界或输入 dtype/device，因此这张表是正确使用契约，不能说运行时已防住全部误用。D=8 是主实验地址数，D=2 是数值校验，D=1 是适应反例；函数未硬编码 D=8。

**实测边界。** [新轨迹脚本](复现/scripts/trace_contracts.py) 将 w=[[1,-1]]、k=[1,0]、v=21 送入 write，得到 L2=[[5,-1]]、Huber=[[1.1,-1]]，输入 w 完全不变。零梯度 alpha=.98 得到 [[.98,-.98]]，说明衰减会影响所有列。mode='bad' 抛 ValueError；长度3的 key 对 [1,2] 状态抛 size mismatch。把 v 错传成长度2向量却被广播接受，仍返回 [1,2]：这不是正确的双输出状态，不能用“不报错”证明支持多输出。检查保留了这些事实，没有偷偷修改原脚本。

### 12.2 更新代码：读出、残差、梯度、返回状态【必须会】

原代码：

~~~python
error=(w@k).squeeze()-v
if mode=='l2': derivative=error
elif mode=='huber': derivative=error.clamp(-delta,delta)
else: raise ValueError(mode)
return alpha*w-eta*derivative*k.unsqueeze(0)
~~~

一句话：根据当前地址的预测误差返回新记忆。这是每一次写入的核心，因为两个更新器接收相同观测，差别只在 derivative。torch.Tensor 的 @ 是矩阵乘法；squeeze 不传 dim 会去掉所有大小为1的维度；clamp 限制数值区间；unsqueeze(0) 插入一个行维度。

第一行 w@k 产生 [1] 的读出，squeeze 成零维数值，减 v 得残差。两条分支分别选择残差本身或截断残差作为误差导数；raise 主动报告非法模式。最后一行 alpha*w 先保留旧状态，derivative 乘行向量 k[None,:] 得 [1,D] 梯度，再乘 eta 并相减。没有 +=、copy_ 等原地操作；调用者必须接住返回值才能推进状态。

| 变量 | 命名来源/含义 | 类型 | 当前形状→下一步 |
|---|---|---|---|
| w | weight，旧记忆矩阵 | float64 Tensor | [1,D] → matmul/保留分支 |
| k | key，地址 | float64 Tensor | [D] → [1,D] 梯度因子 |
| v | value，观测目标 | float/零维 Tensor | [] → 残差 |
| error | prediction error，预测−目标 | float64 Tensor | [] → 模式分支 |
| derivative | 标量损失对残差的导数 | float64 Tensor | [] → 广播乘 key 行 |
| eta/alpha/delta | 步长/保留率/阈值 | Python float | 标量配置，无 batch/head 维 |
| 返回值 | 更新后的状态 | float64 Tensor | [1,D] → states[m] 或下一次 w |

形状路线完整写为 [1,D]@[D]→[1]→[]→[]×[1,D]→[1,D]。标量广播是合理使用；多输出时正确外积应写 e[:,None]*k[None,:]，但本函数不是那种实现。paper↔code 对应 §5 半平方损失与公式 13/26 单输出梯度，缺完整 MLP 链式导数和输入相关门。

### 12.3 核验代码：为什么需要 autograd 和独立归一化【建议会】

原代码片段：

~~~python
g,=torch.autograd.grad(loss,w)
inferred=(w.detach()-write(w.detach(),k,v,mode))/.2
assert torch.allclose(g,inferred,atol=1e-12)
state=torch.softmax(.97*state.log()-.1*grad,dim=0)
~~~

一句话：用独立求导与不变量核对更新表达式。这里 loss 是零维 float64 Tensor，w=[1,2] 且 requires_grad=True。autograd.grad 返回 tuple；g, 是解包其唯一梯度，不是二维索引。g=[1,2]；detach 返回同值但不记录该校验分支的梯度。由于 alpha=1，新旧状态差除步长得到代码隐含的梯度 [1,2]，allclose 比较它与独立 autograd。assert 失败会抛 AssertionError；未用 python -O 关闭断言。

checks 的 Huber loss 通过 torch.where 的两段表达式定义；where 选择区间值并由 PyTorch 求导，不是手写 clamp 再与自身比较。因此这里确实有两条计算路径。三个样本覆盖平方损失、大残差 Huber、小残差 Huber，未覆盖所有 dtype/device 或边界配置。

最后一行属于另外的 KL 算子核验：state 和 grad 均为 [4,4]，log 保持形状，乘保留率再减梯度，Softmax 沿行方向生成 [4,4] 新状态；state.sum(0) 得 [4] 列和。grad 来自局部随机生成，**不是完整 Memora MLP 的真实损失梯度**。循环100次仅测试该更新算子保持正性、列和及遗忘偏好的性质。state.log 要求正输入；本实验从 .25 开始并用 Softmax 保持正性，未证明所有 float32 极端值下不下溢。

更一般的 Huber 不能靠标量测试判一致。新脚本对 e=[2,.25]、delta=.5 算出：逐坐标 Huber 导数 [.5,.25]；对整体 L2 范数的 Huber 导数约 [.496139,.062017]；整体范数决定大误差分支再用 L1 导数得到 [.5,.5]。三者在真实多输出残差上不同，对应原公式 13—16/26 的区分；这是直接数值分析，不是新训练模型。

### 12.4 数据与评估代码：一条样本走到哪里【必须会】

原代码片段：

~~~python
observed=target[keys]+noise+20*sign*spikes
states={m:torch.zeros(1,8,dtype=DT) for m in ['l2','huber']}
for i in range(500):
    for m in states:
        states[m]=write(states[m],eye[keys[i]],observed[i],m)
        traces[m].append(float((states[m].squeeze()-target).abs().mean()))
~~~

一句话：生成同一条污染流，让两个更新器逐步写入后评估所有地址。该段处在 main→corrupted_stream→write 的真实数据路径中；没有 data loader 或 tokenizer。

Generator.manual_seed(seed) 建立局部随机数流；randint 采地址，randn 采标准高斯噪声，rand 采均匀概率，where 根据布尔条件选择正负号。target 由 arange(8)%2 构造交替±1。第一行 target[keys] 是索引，不是矩阵乘法；布尔 spikes 与浮点数相乘变成0或对应异常幅度。字典推导式为每个模式单独调用 zeros，生成独立 Tensor；for m in states 遍历字典键。i 从0到499，keys[i] 为零维整数索引，eye[keys[i]] 从 [8,8] 单位矩阵取一行 [8]，因此每条观测只指向一个地址。

调用 write 后给 states[m] 重新赋值；squeeze 后 [8] 与 target[8] 相减，abs 得绝对误差，mean 在八个地址上平均得到零维 Tensor，float 转成 Python 数字，append 写入该模式 list。one-hot 表示读取每个地址就是状态对应系数，因此无需另对八个 query 做矩阵乘法。mode 循环不会更改 observed，两种方法公平共享输入。

| 变量 | 来源和含义 | dtype/type | 形状与流向 |
|---|---|---|---|
| target | 8地址真实内容 | float64 Tensor | [8] → target[keys]/误差参考 |
| keys | 500条地址编号 | int64 Tensor | [500] → 单项[] → eye行 |
| noise | 高斯扰动 | float64 Tensor | [500] → observed |
| spikes | 是否污染 | bool Tensor | [500] → 异常量 |
| sign | 异常正负方向 | float64 Tensor | [500] → ±20 |
| observed | target索引+噪声+异常 | float64 Tensor | [500] → 单项[] → write |
| eye | one-hot 查询表 | float64 Tensor | [8,8] → [8] key |
| states | 两种方法的独立记忆 | dict[str,Tensor] | 每值[1,8] → 每步新值 |
| traces | 检索误差轨迹 | dict[str,list[float]] | 每列表500项 → 后半段平均 |

本次原种子2026的污染流重放与旧 JSON 完全相等，两模式各500项，实测13个污染观测。3% 是每观测的概率，不保证每条500长度流恰好15条异常。clean/outlier 使用相同 seed 时 key/noise/sign 的抽样次序一致，污染阈值不同；L2/Huber 更是共享已经生成的同一 observed。

## 13. 已运行的小 demo

任务是真值为交替 ±1 的 8 个 one-hot 地址，每个 episode 顺序写 500 次。对照两种流：仅标准差 0.05 的高斯噪声；同样噪声但 3% 的观测再加 ±20 异常值。100 个 episode，种子 2026—2125，每个 episode 对两种更新器共享输入。

主要指标是每个 episode 第 251—500 步的八地址平均绝对误差，再对 episode 取均值。不是 token accuracy、ppl 或 NIAH 分数。图中误差棒是跨 episode 均值标准误，未假称 95% 置信区间。

| 数据流 | 平方误差写入 | Huber 写入 | 解释 |
|---|---:|---:|---|
| clean | 0.013288 | 0.013321 | 在此噪声范围内几乎一样 |
| 3% outliers | 0.529372 | 0.022535 | Huber 限制异常写入量 |

异常流平方误差跨 episode std=0.16343，Huber=0.003390；均值标准误分别为 0.016343 与 0.000339。差异是这个人工生成任务的测量，不能泛化成所有任务相同倍数的改善。

另一个确定性实验：已经存好的标量真实值从 1 永久变成 3，要求绝对误差 <0.1。平方误差 14 次更新达到要求，Huber 23 次。这个反例说明阈值不是免费收益：越谨慎接纳大残差，越可能拖慢真正的新知识。
